# MoneyFlow

Простое приложение для учёта доходов, расходов, целей и кредитов. Работает как PWA: устанавливается на телефон со своей иконкой, открывается без интернета и хранит все данные только на устройстве, в зашифрованном виде.

## Как опубликовать на GitHub Pages (≈10 минут, нужен компьютер)

1. Зарегистрируйтесь на github.com, если ещё нет аккаунта.
2. Нажмите «+» → **New repository**. Название `moneyflow`, тип **Public**. Нажмите **Create repository**.
3. На странице репозитория нажмите ссылку **uploading an existing file**.
4. Распакуйте архив и перетащите в окно браузера **всё содержимое** папки `moneyflow`, включая папку `icons`. Сам zip-архив загружать не нужно.
5. Нажмите **Commit changes**.
6. Откройте **Settings → Pages**. В блоке *Build and deployment* выберите Source **Deploy from a branch**, ветку **main** и папку **/ (root)**. Нажмите **Save**.
7. Через 1–2 минуты приложение откроется по адресу `https://ВАШ-ЛОГИН.github.io/moneyflow/`.

## Как установить на телефон

- **iPhone (Safari):** откройте адрес, затем «Поделиться» → «На экран Домой».
- **Android (Chrome):** откройте адрес, затем меню ⋮ → «Установить приложение» или «Добавить на главный экран».

## Как выпустить обновление

1. Замените изменённые файлы в репозитории.
2. В файле `sw.js` поднимите версию, например `moneyflow-v1.0.0` → `moneyflow-v1.0.1`.
3. При следующем запуске пользователи увидят «Доступна новая версия» с кнопкой «Обновить».

## Безопасность

- Данные шифруются по AES-256-GCM. Ключ защищён PIN-кодом (PBKDF2, 600 000 итераций) и, по желанию, биометрией (WebAuthn PRF).
- После 5 неверных PIN-кодов ввод блокируется, и с каждой новой ошибкой пауза растёт.
- Приложение не обращается к сторонним серверам и не содержит аналитики. Политика безопасности (CSP) запрещает загрузку чужих скриптов.
- Резервная копия шифруется отдельным паролем.
- Если пользователь забыл PIN, данные можно только удалить и восстановить из резервной копии.

## Файлы

- `index.html` — страница приложения
- `app.js` — логика
- `i18n.js` — переводы (UA/RU/EN)
- `style.css` — стили
- `sw.js` — офлайн-режим и обновления
- `manifest.webmanifest`, `icons/` — установка на телефон
